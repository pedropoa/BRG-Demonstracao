# BRG — demonstração não oficial

Proposta visual de página única para a Balanças Riograndense. Não substitui a instalação atual do WordPress.

## Visualizar localmente
Abra `index.html` no navegador. Nenhuma instalação é necessária.

## Publicação de demonstração no GitHub Pages
1. Crie **um repositório público separado**, por exemplo `BRG-Demonstracao`, na sua conta GitHub. Nunca use o repositório MIL.
2. Envie `index.html`, `styles.css`, `script.js` e `.nojekyll` para a raiz.
3. No repositório, entre em **Settings → Pages**. Em **Build and deployment**, escolha **Deploy from a branch**; selecione **main** e **/(root)** e salve.
4. Confira o endereço indicado pelo próprio GitHub Pages na tela de configurações.
